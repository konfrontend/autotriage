# Letter template: build

Greenfield, or a rewrite where existing code is not the starting point. The Letter carries our own milestone plan with prices; the client takes it or leaves it.

Slot notes for this Family:

- `milestones`: our plan, not the client's feature list. Milestone 1 is a thin end-to-end slice (one user, one path, deployed). Each line carries a price from the Profile rate, except on a client-priced test (no prices); weights uneven. When the posted budget covers a minimum viable scope at the Profile floor, deferred milestones are listed last and marked as deferred so the funded total fits the budget. Otherwise the plan ignores the posted budget.
- `stack`: always on. Client's preferred list first when they gave one.
- `relevant_work`: three Past Jobs by default. Prefer ones where something was built from nothing and shipped.
- `billing`: the funded total, what is deferred, acceptance against a written check per milestone. The rate appears here.
